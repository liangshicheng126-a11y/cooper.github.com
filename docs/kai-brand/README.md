# KAI 品牌基础包

版本：0.1  
定位：企业模型服务容量市场基础设施  
方向名称：时间栅格（Temporal Grid）

## 1. 品牌核心

KAI 让企业在确定的时间、区域和模型标准下，获得可计划、可比较、可交付的模型服务容量。

| 层级 | 定义 |
| --- | --- |
| 品牌角色 | 中立的模型服务容量市场基础设施 |
| 首要受众 | 需要业务连续性与预算确定性的企业采购、AI 平台和运营团队 |
| 次要受众 | 容量供应商、模型发布方、聚合商、风控与结算合作伙伴 |
| 核心承诺 | 将未来模型服务容量转化为可验证的企业采购产品 |
| 品格 | 中立、精确、稳健、透明、协同 |
| 品牌语气 | 清楚、克制、可核验；先讲规则与价值，再讲愿景 |

## 2. 命名与信息架构

- 中文名称：KAI 期算
- 英文名称：KAI Model Capacity Market
- 首次出现：`KAI 期算（KAI Model Capacity Market）`
- 简短描述：`企业模型服务容量市场`
- 避免使用：`算力交易所`、`AI 金融平台`、`GPU 期货`、`投机`、`暴利`

推荐叙事顺序：**场景中的容量不确定性 → KAI 的标准化方式 → 可交割与风险治理 → 生态与规模化**。

## 3. 视觉方向：时间栅格

标志符号由四条路径组成：左上、右上、左下与右下的节点共同定义一个“可交割的小时窗口”。其含义不是数据流炫技，而是四项企业采购保证：

1. 时间窗口：指定交割小时。
2. 容量路径：可度量、可分配的 TPM。
3. 验证节点：标准、结算和履约可审查。
4. 开放连接：多供应商而非单一资源池。

### 视觉原则

- 用深色底与高对比留白建立机构级可信度。
- 以细线、栅格、路径、坐标和克制的高亮表现规则与流动。
- 以靛蓝作为识别主色；青色只用于状态、连接和关键数据。
- 图片应呈现数据中心、企业运营、城市网络或抽象工业秩序；避免芯片特写、机器人头像、霓虹赛博城、币圈图形和股票 K 线。
- 图形不应暗示价格投机。价格曲线只能作为带有时间、模型、区域和交付标准标签的严谨数据图。

### 使用规范

- 主标优先用于正式对外触点；小于 160px 宽时使用符号加文字，不再使用副标题。
- 图标最小尺寸：数字端 20px；印刷端 7mm。
- 主标四周至少保留一个符号方格宽度的留白。
- 深色主标仅置于深海军蓝背景；浅色场景使用墨色单色版本（后续制作）。
- 不拉伸、不描边、不加投影、不旋转符号；不将图标与“AI”“算力”泛化图标混合使用。

## 6. 关键触点模板

| 触点 | 版式规则 |
| --- | --- |
| 白皮书 | 深色封面、明显版次与日期；章节页只使用一个栅格母题；数据表保留充足留白。 |
| 官网 | 首屏用“确定时间内的可交割容量”作为价值主张；产品、交付、治理三层内容并列。 |
| 商务演示 | 每页一个结论；图表使用模型/区域/时段/标准四个标签，不用孤立的价格数字。 |
| 供应商资料 | 以资格、交付、评分、结算为主叙事；避免“市场热度”“收益”式措辞。 |
| 社媒 | 使用符号、短句与一条路径图形；背景保持纯净，不用高频赛博视觉。 |

## 7. 动效原则

- 交互与页面动效应表现为路径逐步连接、窗口被确认、容量模块平稳入位。
- 动画速度应偏稳健，避免爆炸、弹跳、故障风和高频闪烁。
- 为 `prefers-reduced-motion` 提供静态栅格与直接状态切换。

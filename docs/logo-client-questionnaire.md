# Logo 设计客户需求问卷

适用场景：客户还没想好具体样子时，用这份问卷把「模糊感觉」变成可执行的设计 brief。建议客户用文字/图片混答；标 ★ 的为优先必答。

---

## 一、企业与品牌基础

**1. ★ 请用 2–3 句话介绍公司：做什么、为谁服务、和同行最大的不同是什么？**  
（比「我们是做 XX 的」更有用，能挖出定位与差异点。）

答：

**2. ★ 公司全称、常用简称、对外品牌名分别是什么？Logo 必须出现哪些文字？有无注册/商标限制？**  
（含英文名、拼音、是否必须带「有限公司」等。）

答：

**3. ★ 目标客户是谁？（年龄、行业、消费习惯、地域；B2B 还是 B2C？）**  
（Logo 要「说」给谁听，比老板个人喜好更重要。）

答：

**4. 用 3–5 个词描述你们希望品牌给人的感觉。**  
示例：专业、可靠、年轻、科技、温暖、高端、有趣、稳重、先锋……也可写「不要显得……」。

答：

## 二、竞品与参照

**5. ★ 列出 2–3 家主要竞品或同类品牌，并说明：你们希望和他们「像」还是「故意不像」？哪里像/不像？**

答：

**6. ★ 请各举 1–3 个例子（可贴图或发链接）：**  
- 喜欢的 Logo / 品牌视觉（说明喜欢哪里：字体、图形、颜色、气质）  
- 不喜欢的 Logo / 风格（说明讨厌哪里）  
（没有设计术语也没关系，用「太花」「太老气」「太网红」等口语即可。）

答：

---

## 三、风格与视觉方向

**7. ★ 更倾向哪一类？（可多选，并请排序）：**  
- [ ] 纯文字（Wordmark）  
- [ ] 图形+文字（图文组合）  
- [ ] 字母/首字母标（Lettermark）  
- [ ] 抽象符号  
- [ ] 具象图形（与业务相关的物体/场景）  
- [ ] 徽章/印章感  
- [ ] 不确定，希望设计师给方案  

排序 / 补充说明：

**8. 颜色：有没有必须用的品牌色？有没有绝对不能用的颜色？对「彩色 / 单色 / 深色底 / 浅色底」有偏好吗？**  
（若已有 VI 或官网色，请一并提供。）

答：

**9. 是否有必须出现或绝对不能出现的元素？**  
例如：必须有某吉祥物、必须体现某行业符号；不能用动物、不能用渐变、不能太卡通、不能像某知名品牌等。

答：

## 五、决策、预算与时间

**13. ★ 谁最终拍板？评审时通常几个人、按什么标准选？（好看 / 好记 / 好用在门头 / 老板个人喜好等）**  
（提前知道决策链，可减少反复改稿。）

答：

**14. 期望的时间节点与预算区间？是否有对外发布日、开业日、展会等硬截止日期？**  
（预算可用区间回答，不必精确到元。）

答：

**15. 还有什么希望设计师知道、但上面没问到的？**  
（企业文化、创始人故事、忌讳、行业监管要求等开放题。）

答：

## 使用建议（设计师自用）

- 客户答完后，再补一轮 **15 分钟语音确认**：把问卷里矛盾处（例如「要高端」又「要很热闹」）当场对齐。
- 若客户几乎空白，优先追问 **1、3、6、7、10**——这五题通常就能定方向。
- 可把第 6 题做成「Moodboard 收集表」（飞书/问卷星上传图），比纯文字有效得多。

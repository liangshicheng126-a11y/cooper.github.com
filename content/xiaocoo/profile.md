- 第三阶段 · 后期精修与延展（质量把控）
  - 工具：PS AI；Cursor 图像 skill / MCP
  - 应用：在后期调用 Cursor 的图像 skill 与 MCP，在 PS 与 AI 中快速做画面延展和瑕疵修复，将原本数小时的修图缩短到分钟级，把精力留给品牌策略与视觉逻辑。
